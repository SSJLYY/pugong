## 0. 一句话定义

一款**反等级制 + 硬核死亡制 + 普攻赋能转生制**的大数放置游戏：
没有等级，没有经验值，只有属性面板。
每一次普攻，永久 +1 生命上限——**但死了，档就没了。**
而当你的拳头快到一秒一载次，便可通关飞升、转世重修——**下一世，你的普攻除了涨血，还能涨别的。**

核心设计哲学：**血量即经验值，攻速即经验倍率，出拳即修行，存档即纪律，万世即传承。**

## 1. 世界观

### 1.1 设定

凡尘大陆流传着一句古训：

> 「出一次拳，身子就结实一分。」

这片大陆上不存在"等级"。冒险公会的委托牌上写的不是"XX 级以上可接"，而是直白的属性门槛——"生命 ≥ 5000，攻击 ≥ 50，方可接取"。

但古训还有后半句，鲜有人提：

> 「拳头再硬，命只有一条。」

大陆没有复活术。战死者的一切修为随尸体入土，只在村口的**墓园**里留下一块碑，碑上刻着他生前最后一次存档的面板。老冒险者的第一课永远不是怎么打架，而是——**动手之前，先存档。**

而古训真正的最后一句，只有站在大陆尽头的人才读得到：

> 「拳至一载，肉身成圣；拳意不灭，转世续缘。」

传说当一个人的出拳速度快到一秒一载次，便会肉身飞升。但拳意不会消散——它会投胎成一个新生命，带着前世的某项领悟重新出拳。这一世，婴儿的每一拳不只结实一分，还多了一分前世留下的东西：也许是更利的拳锋，也许是更厚的皮，也许是更快的拳。

而当拳意历经十二世、把能领悟的都领悟遍了，往后的每一世，领悟不再增多——只是更沉。
同一项领悟，一分变两分，两分变三分。拳意入化境，一拳，重过前世十拳。

### 1.2 主角

无名武夫。初始面板低得令人发指：**生命 100 / 物攻 1 / 魔攻 0 / 物防 1 / 魔防 0 / 攻速 1.0 / 蓝量 50**。

从村口打木桩开始。一拳，一拳，又一拳。一拳 +1 血。
一亿拳，就是一亿血。一载拳，便是一载血——然后，转世。

### 1.3 主题气质

**笨办法修仙 + 一条命的谨慎 + 万世传承的浪漫。**
血量数字永远向上跳动是信仰；"存档"按钮上磨出的指痕是活人的共同记忆；而墓园里那一排刻着"第 X 世"的碑，是你一个人的编年史。

### 1.4 与 136 现有放置游戏的差异化定位

| 现有游戏 | 核心循环 | 本作的差异 |
|---|---|---|
| Kittens（猫国建设者） | 资源采集→建造→科技 | 本作唯一被动资源是血量 |
| 挂机破坏神 | 刷装备掉宝 | 本作装备是词条取舍，且**死亡掉档** |
| 天机挂机修仙录 | 境界突破 | 本作反境界反等级，突破靠"转世" |
| Synergism / 真·指数 | 转生重置膨胀 | 本作转生**不清空成长维度而是增加成长维度** |
| 量子采石场 | 挖矿科技树 | 本作无科技树 |

**本作独占卖点：**
1. 成长动作 = 战斗动作，二者合一
2. 无等级纯属性，装备技能全是外物加减法
3. **硬核死亡制 + 战前存档**——放置游戏里罕见的"怕死"体验
4. **普攻赋能制转生**：每通关一次，普攻多养一条属性，万世叠加
5. 攻速无上限，数值一路膨胀进中文大数（亿兆京垓秭穰沟涧正载）

## 2. 核心数值体系

### 2.1 属性列表（属性即一切）

| 属性 | 缩写 | 初始值 | 来源 | **转生赋能步长** | 说明 |
|---|---|---|---|---|---|
| 生命上限 | HP | 100 | **普攻 +1/次（先天自带）** | +1（第0世已赋能） | 核心资源，档内永久 |
| 当前生命 | curHP | 100 | 受击扣减 / 回血恢复 | — | 归零 = 死亡 = 删档 |
| 蓝量上限 | MP | 50 | 装备、技能 | +1/拳 | 技能消耗 |
| 当前蓝量 | curMP | 50 | 释放扣减 / 蓝回复 | — | |
| 物理攻击 | PATK | 1 | 武器、装备、技能 | +1/拳 | 物伤结算 |
| 魔法攻击 | MATK | 0 | 法武、附魔、技能 | +1/拳 | 魔伤结算 |
| 物理防御 | PDEF | 1 | 装备、技能 | +1/拳 | 减免物伤 |
| 魔法防御 | MDEF | 0 | 装备、技能 | +1/拳 | 减免魔伤 |
| 攻速 | ASPD | 1.0 次/秒 | 武器、词条、技能 | **+0.01/拳** | **无上限，通关标尺** |
| 攻击距离 | RNG | 1（近战） | 武器、词条、技能 | +0.001 步/拳 | 手长打手短 |
| 移速 | SPD | 100 | 装备、技能 | +1/拳 | 跑图/先手/逃跑/风筝 |
| 暴击率 | CRIT | 5% | 词条、技能 | +0.01%/拳（封顶100%） | 触发暴击 |
| 暴击伤害 | CRITD | 150% | 词条、技能 | +0.1%/拳 | 暴击倍率 |
| 命中 | ACC | 95% | 装备、技能 | +0.01%/拳（封顶100%） | miss 不加血！ |
| 闪避 | EVA | 0% | 装备、技能 | +0.01%/拳（封顶95%） | |
| 生命回复 | REGEN | 0/秒 | 词条、技能、食物 | +1/拳 | 生存核心之一 |
| 蓝量回复 | MREGEN | 1/秒 | 词条、技能 | +0.1/拳 | 技能续航 |

设计红线：
- **血量上限永不回退**（燃烧生命烧当前血不烧上限；死亡=删档，不叫回退，叫重开）
- **攻速无上限**：乘区全部放开，终局一秒 1 载次 = 当世通关
- 生存五件套：**血厚 + 回血 + 攻速 + 暴击率 + 暴击伤害**
- **可赋能属性共 13 条**（HP 先天自带，另 12 条待选：PATK/MATK/PDEF/MDEF/ASPD/RNG/SPD/CRIT/CRITD/ACC/EVA/REGEN）；前 12 次转生每次新增一条，第 12 世集齐，**第 13 世起转生改为强化已有赋能的步长**（见 §12.4）
- MP/MREGEN 不入赋能列表——蓝是消耗品不是修为，永远靠装备/技能/药剂这些外物
- 百分比属性赋能设封顶（CRIT/ACC 100%、EVA 95%），到顶后该项在转生界面置灰不可再强化

### 2.2 核心循环（游戏引擎的第一行代码）

```
每 1/ASPD 秒，角色自动普攻一次：
  if 命中判定失败(miss):
      不触发任何效果
  else:
      按当世赋能列表结算永久成长：
        生命上限 +1
        [第1世起] 自选属性A +步长
        [第2世起] 自选属性B +步长
        ...
      伤害 = 物伤 + 魔伤（见 §2.3）
      if 目标死亡: 掉落结算 → 自动寻下一目标
```

**打木桩（无敌方目标）也照常赋能成长**——出拳本身就是修行。

### 2.3 伤害公式（物理/魔法双轨）

```
物伤 = max(1, PATK × (1±10%浮动) × 暴击判定 - 目标PDEF × 0.8)
魔伤 = max(1, MATK × (1±10%浮动) × 暴击判定 - 目标MDEF × 0.8)
暴击判定: 概率 CRIT，触发则该段伤害 × CRITD
总伤 = 物伤 + 魔伤（两段独立判定暴击）
承伤同理：敌方 PATK 过你的 PDEF，MATK 过你的 MDEF
```

### 2.4 攻击距离（RNG）与移速的交互

- RNG 单位抽象为"步"：近战 1-2 步，长枪 3 步，弓箭 5-8 步，附魔弓可到 10 步
- 战斗规则：**手长先出手**；双方间距由移速差变化
- 风筝流成立条件：RNG > 怪的 RNG 且 SPD ≥ 怪的 SPD → 怪永远够不到你
- 近战打远程怪必须贴脸：移速不够会被白嫖
- 木桩 RNG 0，永远在原地挨打，新手之友
- 第 X 世若赋能了 RNG，后期会出现"百步之外取怪首级"的奇观

### 2.5 攻速成长与中文大数体系

攻速无上限，数值显示走中文大数格式化：

```
万 1e4 · 亿 1e8 · 兆 1e12 · 京 1e16 · 垓 1e20 ·
秭 1e24 · 穰 1e28 · 沟 1e32 · 涧 1e36 · 正 1e40 · 载 1e44
```

攻速成长曲线（乘区堆叠）：

| 阶段 | ASPD | 构成 | 血量增速 |
|---|---|---|---|
| 初始 | 1 | 徒手 | 60/分 |
| 轻武器期 | 3 | 轻刃+蜂鸟戒 | 180/分 |
| 词条成型 | 30 | 攻速词条×3件+连击 | 1,800/分 |
| 中期乘区 | 1万 | 装备×技能×食物乘区 | 60万/分 |
| 后期膨胀 | 1亿 | 全套乘区堆叠 | 6亿/分 |
| 通关线 | **1载(1e44)** | 全部乘区拉满 | **每秒 +1载 血 → 飞升** |

数值实现：全程使用大数库（break_infinity 式 decimal），JS 原生 number 撑不住。

## 3. 存档与死亡系统（本作灵魂）

### 3.1 硬核死亡制（皇上钦定）

- **死亡无法复活。档没了。**
- 唯一活路：战斗前存过档 → 死亡后可**回档**到存档点
- 没存档就死了 → **大侠请重新来过**（全新开档）

### 3.2 存档规则

- 手动存档：战斗外随时可存；**战斗中不可存档**
- **存档槽：3 个（皇上已批）**，可命名（如"进火山前"）
- 自动存档：回安全区（村口）自动存主槽（可关闭，硬核玩家纯手动）
- 存档内容：完整面板 + 装备背包 + 技能 + 位置 + 当世赋能 + 时间戳
- 存档导出：Base64 文本，可离线保存

### 3.3 死亡画面 + 尸检报告（皇上已批）

```
💀 你死了。

击杀者：熔岩兽（火山）
你的生命定格在：2,349万
本档存活：47 天 13 小时 · 出拳 2.1亿次 · 第 0 世

📋 尸检报告：
  致命一击：魔伤 41万（你的 MDEF 缺口约 38万）
  死亡前 10 秒承伤曲线：██████▂▃▅█
  药剂耗尽于死亡前 6.2 分钟
  建议：MDEF ≥ 400 或 REGEN ≥ 5万/秒 再来
  （挂机死亡时附：当时策略配置 + 最后 10 条击杀序列）

[⚰️ 写入墓园，尘归尘]
[📂 回档到最近存档（2小时前 · 生命 1,800万）]
[🔄 就此长眠，重新开档]
```

尸检报告要点（挂机死亡也必须给全）：
- 死因定量分析：哪段伤害（物/魔）击穿、缺口属性数值
- 时间线：药剂何时耗尽、血线何时跌破策略线、为什么逃跑没成功
- 可执行的改进建议（哪个属性要堆到多少）

### 3.4 墓园（皇上已批：历史阵亡档纪念墙）

- 每个死亡的档、每次通关转生的"前世"，都可在村口**墓园**立碑
- 墓碑内容：玩家命名 + 第 X 世 + 存活时长 + 最终面板快照 + 死因（黑碑）/ 飞升（**金碑**）+ 自定义墓志铭一句
- 墓园纯纪念属性，**不提供任何数值加成**（保持硬核纯粹）
- 入口：村口 + 主界面「🪦 墓园」
- 示例：
  ```
  🪦 墓园
  ─────────────────────────
  ⚫ 无名氏 · 第0世 · 存活2天 · 定格8,000血 · 亡于山贼弓手
     墓志铭：我忘了存档
  ⚫ 老拳师 · 第0世 · 存活31天 · 定格3,000万血 · 亡于炎魔
     墓志铭：魔防，我的魔防
  🟡 拳圣 · 第0世 · 存活66天 · 定格1.2载血 · 飞升
     墓志铭：下一世，拳锋更利
  ```

- 双方按各自 ASPD 独立出手，互不等待
- 先手判定：RNG 长者先出手；RNG 相同比 SPD

## 6. 装备系统（底子 + 词条，暗黑式）

### 6.1 结构

装备 = **底子（部位固有加减法）** + **随机词条（1-4 条）**。
装备无等级，只有属性。脱下装备你还是你。

部位（10 槽）：武器 / 副手 / 弓（远程武器位，与近战武器位互斥）/ 头 / 胸 / 腿 / 鞋 / 戒指×2 / 项链

- 上限 8 小时，效率 50%

## 11. 数值平衡目标（第一版）

### 11.1 第 0 世节奏

| 游玩时长 | 期望血量 | 期望面板 | 可进区域 | 死亡风险点 |
|---|---|---|---|---|
| 10 分钟 | ~600 | 木棍+兔肉 | 平原 | 基本无 |
| 1 小时 | ~4,000 | 铁剑+木盾 | 森林 | 山贼弓手风筝你 |
| 1 天 | ~80,000 | 猎弓+锁子甲+连击 | 沼泽 | 毒蟾耗光血药 |
| 1 周 | ~500,000 | 附魔弓+双防成型 | 雪山 | 冰法魔伤秒人 |
| 1 个月 | ~3,000万 | 词条毕业套 | 火山 | 炎魔双伤混合 |
| ~2-3 个月 | 亿→兆→…→载 | 攻速乘区拉满 | **通关飞升** | 只有自己作死 |

### 11.2 万世节奏（转生后加速）

- 第 1 世：普攻 +1 HP +1 <自选属性>，若选了 PATK → 全程秒怪，通关时间预计缩到第 0 世的 1/3
- 第 2 世：三条赋能线，若补了 ASPD（+0.01/拳）→ 攻速自我繁殖，通关再提速
- 第 3~12 世：赋能线逐世增加，第 12 世集齐 13 条，"全属性自我成长"达成
- **第 13 世起（强化纪元）**：赋能条数不再增加，但每次转生让步长升级（HP +1/拳 → +2/拳 → …），成长斜率本身开始膨胀，通关时间继续压缩
- 设计目标：**每一世都比上一世快，但永远需要"挂机的时间"**——放置游戏的本质不能丢；同时游戏**没有终点**，万世无穷

平衡红线：
1. 攻速无上限但乘区曲线要陡
2. 血量上限永不回退；死亡删档是唯一惩罚
3. 生存五件套：血厚 + 回血 + 攻速 + 暴击率 + 暴击伤害
4. 怪物全属性制：高防低速、高速低防、远程脆皮，处处取舍
5. 转生不清空"成长维度"，只重置面板——**传承的是能力，不是数字**

## 12. 转生系统（通关即飞升，普攻赋能制）

### 12.1 触发条件

**ASPD 达到 1 载次/秒（1e44）= 当世通关。**
通关瞬间全屏特效：拳头快出残影 → 天地失声 → 飞升动画（纯文字版：满屏"+1"汇成光柱）。

### 12.2 转生仪式

```
⚡ 你的拳速已达一秒一载次。
   肉身成圣，当世通关。

   第 0 世结算：
   存活 66 天 · 出拳 3.7载次 · 最高生命 1.2载 · 击杀 89万

   选择本世领悟，带往来生：
   你的普攻将永久新增一项成长——
   [🗡️ 物攻+1/拳] [✨ 魔攻+1/拳] [🛡️ 物防+1/拳] [🔮 魔防+1/拳]
   [⚡ 攻速+0.01/拳] [👢 移速+1/拳] [🏹 射程+0.001/拳]
   [💥 暴击率+0.01%/拳] [💢 暴伤+0.1%/拳] [💚 回血+1/拳]
   [💙 蓝量+1/拳] ...
```

- **自选**（build 策略性）：玩家从属性列表挑一个加入普攻成长
- **第 1~12 次转生**：每项属性只能赋能一次，不可重复选；第 12 世集齐全部 13 条赋能
- **第 13 次转生起（第 13 世通关后，进入强化纪元）**：赋能列表已无可新增项，转生仪式改为——**自选一条已有赋能，让步长升级**（例：原来普攻 +1 生命上限，此后 +2 生命上限）
- 前世写入墓园（金碑；第 12 世通关集齐全属性时立**圆满金碑**，墓园置顶）

### 12.3 转世规则

| 项目 | 规则 |
|---|---|
| 面板 | 重置回初始（HP 100 / PATK 1 / ...） |
| 普攻赋能 | **永久继承并累积**（第 N 世 = HP + N 条自选属性） |
| 装备/背包/金币 | 清空（修为随身，外物不带） |
| 技能 | 清空（技艺随肉身） |
| 墓园/图鉴/成就 | 保留 |
| 世代显示 | 界面常驻「第 X 世」 |

### 12.4 赋能叠加总表 & 强化纪元

| 世代 | 普攻永久成长 | 通关时间预估 |
|---|---|---|
| 第 0 世 | +1 HP | 2-3 个月 |
| 第 1 世 | +1 HP，+1 〈自选A〉 | ~1 个月 |
| 第 2 世 | +1 HP，+1 〈A〉，+1 〈B〉 | ~2 周 |
| 第 3 世 | 四条成长线 | ~1 周 |
| … | 逐世加速 | 逐世缩短 |
| 第 12 世 | **13 条赋能全部集齐**（最后一世新增项） | 数日 |
| **第 13 世起 · 强化纪元** | 不再新增属性，每次转生**自选一条已有赋能步长 +1 级** | 越来越短 |

强化纪元的步长升级规则（皇上钦定"原来+1现在+2"）：

| 赋能项 | 初始步长 | 强化第1次 | 强化第2次 | 上限 |
|---|---|---|---|---|
| HP | +1/拳 | +2/拳 | +3/拳 | **无上限** |
| PATK/MATK/PDEF/MDEF/SPD/REGEN | +1/拳 | +2/拳 | +3/拳 | 无上限 |
| ASPD | +0.01/拳 | +0.02/拳 | +0.03/拳 | 无上限（自我繁殖，数值失控的浪漫） |
| RNG | +0.001步/拳 | +0.002/拳 | +0.003/拳 | 无上限 |
| CRIT/ACC | +0.01%/拳 | +0.02%/拳 | … | 属性值封顶 100%，到顶置灰 |
| EVA | +0.01%/拳 | +0.02%/拳 | … | 封顶 95%，到顶置灰 |
| CRITD | +0.1%/拳 | +0.2%/拳 | … | 无上限 |

- 强化同一项可无限叠加：HP 赋能强化 5 次 = 每拳 +6 生命上限
- 转生无次数上限，游戏**没有终点**——万世之后，一拳千血、百步穿杨、出手成风暴

设计意图：
- 转生**不是重置游戏，是拓宽游戏**——每一世的 build 思路都不同（先攻后防？先攻速后暴击？）
- 赋能 ASPD 是数值爆炸奇点（攻速自我繁殖），**不限制，让它爽**——大数放置的终极浪漫就是失控
- 若某世作死死亡且没存档：该世结束，但已累积的赋能与强化等级保留（拳意传承，死亡夺不走）——**死亡惩罚的是当世面板，不是万世传承**

## 14. 技术方案（写代码阶段执行）

- 预留 `window.__game` 状态对象与 API（自动管家）
- 部署：`/data/games/gongpu/`，portal 加卡片，footer 计数 +1
